# 星鉴 · 紫微斗数

by 天水一壤
https://zhaoy6859-svg.github.io/ziwei-xingjian/#start
一个纯静态的紫微斗数排盘与解读页面。输入出生时间，排十二宫方盘，读命身、十二宫、四化、格局、大限、流年与流月。所有计算在浏览器本地完成，不上传出生信息，不需要登录。

## 这一版改了什么

- **解读从 9 篇扩到 26 个维度**：总览 4 篇、十二宫 12 篇、专题 6 篇、运限 3 篇、收束 1 篇。
- **内容粒度从“星曜 × 六个主题”改成“十四主星 × 十二宫”**：每颗主星在每一个宫位都有单独的分宫断语，不再用同一段话套十二个宫。
- **说话方式重写**：减少“你可以试试”“也许”“可能”的咨询式套话，改成先给判断、再讲盘面、最后落到具体做法的写法；保留“倾向不是定数”的边界。
- **补上四化、格局、身宫、三方四正、大限、流年、流月**：四化落宫、常见格局结构、当前大限与近三年流年都有独立解读。
- **移除 ChatGPT Sites 的挂件脚本**：页面现在是纯静态 HTML/CSS/JS，可直接部署到任意静态托管，公开访问、点开即用。
- **保留原版视觉**：首页题诗、罗盘、纸盘、十二宫方盘、墨金配色都没有改。

## 本地预览

在这个目录执行：

```bash
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。不要直接双击 `index.html`：原版 CSP 在 `file://` 下可能拦截本地脚本；本地预览用上面的 HTTP 方式最稳。

## 生成发布包

```bash
python3 build.py
```

会生成：

- `dist/星鉴.html`：单文件版，CSS/JS/SVG 全部内联，双击即可打开，也可以直接上传到任何静态托管。
- `dist/site/`：多文件版，入口是 `index.html`，适合正常静态托管。
- `dist/星鉴-紫微斗数.zip`：把 `dist/site/` 打包，方便上传。

## 公开部署

任选一种，都是公开、无需登录、点开即用：

1. **Netlify Drop**：把 `dist/site/` 拖到 Netlify Drop，得到公开网址。
2. **Cloudflare Pages / GitHub Pages / Vercel**：把 `dist/site/` 作为静态站点上传；入口 `index.html`。
3. **任意静态空间 / 对象存储**：上传 `dist/site/` 的全部内容，确保 `index.html` 在根目录。
4. **只想发一个文件**：上传 `dist/星鉴.html`，或直接发给别人双击打开。

如果继续用 ChatGPT Sites：把 `dist/site/` 里的文件替换到项目里，入口用 `index.html`，不要带回原来的 `sites-widget.js` 挂件；发布时把访问权限设为公开即可。

> 说明：`fonts.css` 会从 Google Fonts 拉取 Noto Serif SC。若访问环境拉不到，字体会自动回退到系统宋体/楷体，页面功能不受影响。

## 生成方式（重要）

- **盘面**：由 `iztro.js` 计算十二宫、主星/辅星、亮度、生年四化、大限、流年、流月。`iztro` 是排盘库，不是“紫微斗数 skill”。
- **解读**：由 `reading.js` 按 `star-library.js`（十四主星 × 十二宫）和 `reading-library.js`（辅曜、四化、格局、专题）的规则组合生成。文字是我写的规则库，不是古籍原文，也不是某位命理师的亲断。
- **运行时没有模型调用**：同一张盘、同一个解读基准日，输出固定；换日期/时辰/性别只会换盘面和运限，不会临时“问 AI”。
- **边界**：格局检测（杀破狼、机月同梁、四桃花、煞曜偏聚等）是结构提示，不是严格古法格局；四化落宫、大限/流年/流月边界依 iztro 的算法，不同流派会有差异。若要严格对齐某个 skill/老师/流派，需要提供该体系的原文或参考盘，我再校准内容库。

## 内容维护

- 改某颗主星在某个宫位的说法：编辑 `star-library.js` 中对应星曜的 `palaces`，格式是 `宫位: ['断语', '正文']`。
- 改四化、格局、辅曜：编辑 `reading-library.js`。
- 改整体结构、专题、大限/流年写法：编辑 `reading.js`。
- 改排版：`styles.css` 是原版样式，`reading.css` 是多维度解读新增部分。
